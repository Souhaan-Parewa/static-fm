# OFF THE AIR 

## about it

you see a radio which is at radio frequency - 87.3 and it is just static.

then something starts coming through.

voices, numbers, strange transmissions and signals that should not be there.

your job is to see whats happening before it goes complete silent.

## how i made it

i made this using HTML for the barebones structure, [Tailwind CSS](tailwindcss.com), Vanilla JS, and the Web Audio API for generating audio directly in the browser.

## how it plays

- tune through the frequency and notice the unusual signals
- interact with the controls and keep an eye on the broadcast logs
- it keeps getting unusual the longer you listen it to
